# Проект: Валидатор вакансий (Хакатон КАНТКОД)

## Описание
Программа на языке Python, которая анализирует базу вакансий в формате JSON и ищет логические противоречия и ошибки в данных (например, нулевую зарплату, несоответствие требуемого опыта в поле и в тексте, противоречия в графике работы и формате работы).

## Инструкция по запуску
Для запуска программы вам потребуется установленный Python (версия 3.6 или выше).

1. Скачайте файлы `validator.py` и `manege.json` в одну папку на вашем компьютере.
2. Откройте терминал (или командную строку) в этой папке.
3. Выполните команду для запуска:
   python validator.py
4. Программа выведет в консоль отчет о найденных ошибках в вакансиях.
